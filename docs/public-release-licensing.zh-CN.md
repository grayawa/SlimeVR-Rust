## 本轮核对范围

- Rust 后端、GPUI、Tauri 的 `cargo metadata --locked` 分别解析了 317、950、
  514 个包，包含多平台和开发依赖，不能把数量直接当作实际 Windows 链接数量。
  已检查声明的许可证表达式。主要是 MIT、Apache-2.0、BSD、ISC 等；少量
  MPL-2.0 包需要保留各自源码及通知义务。声明中的可选 GPL/LGPL 分支有
  MIT 或 Apache 等兼容选项。本轮未发现阻止采用 GPLv3 的许可证声明。
- 检查了本地 pnpm 缓存中的许可声明；构建工具、字体、浏览器兼容性数据
  与最终程序代码分开判断。FlatBuffers 是 Apache-2.0，字体是 OFL/UFL，
  Twemoji 图像是 CC-BY-4.0，不能误用 npm 包装器的 MIT 覆盖图像许可。
- 子模块及 vendor 许可不变，原作者声明和数学参考许可保留。新增的 GPL
  正文不撤销历史 MIT/Apache 授权，也不把第三方材料变成 GPL 专属代码。
- 工作树未跟踪用户日志、vrconfig、证书私钥或上传的压缩包。跟踪的
  `gui/.env` 只有三个固件服务 URL 配置变量。
- 对公开上游基线之后所有本地可达 Git 历史的新增行进行了有限模式扫描，
  覆盖常见 GitHub token、AWS access key 和私钥 PEM 头，共扫描约 153 万
  行，未发现匹配。文档未发现非测试风格的设备 MAC。有限模式扫描不等于
  完整的秘密检测，也未逐条审查全部 GitHub Actions 日志和讨论附件。

  对应源码要求。

## 公开后的许可效果

GPL 允许商业使用、分发与修改。分发 GPL 覆盖的二进制时，需要按许可证
提供对应源码；单纯私下使用或修改不要求上传到 GitHub。上游宽松许可证
仍允许别人使用原有代码；GPL 不能追溯收回已经给出的宽松授权。

SlimeVR 商标许可独立于代码许可，本项目需持续明确独立、非官方身份，不能
宣称由 SlimeVR 官方发行或背书。GPL 专属修改回馈 MIT/Apache 上游，需要
有关权利人另行授权。公开仓库会公开其可达历史及原有讨论、工作流记录；
未来排障附件应遮蔽个人配置、Wi-Fi 密码和真实日志中的私人信息。
