## 3. 资料中需要保留限定的结论

- `BOARD=9` 与 `IMU=13` 已与当前 Server 枚举核对；MCU、晶振、Flash 和实机诊断沿用包内此前记录，本次没有硬件复测。
- `81c57e2` 尚未被确认为上游提交，不能据此确定固件行为或覆盖其升级目标。
- 240/120/60 Hz、两个温度校准点、约 5°C 间隔等来自资料引用的上游路径。资料没有提供厂商 fork 源码及完整实际时序测量。
- `TCAL` 不支持与 runtime gyro-bias 校准存在并不矛盾；temperature-gradient 辅助也不是完整 `bias=f(T)` 曲线。
- 包 23 带 int16，不表示它提供 raw gyro；历史 raw/debug inspection 能力不表示当前 Server 已实现正式在线 raw 融合。
- 资料中的 controller/IK 描述要以当前真实调用链限定。已有 IK 类不等于普通 `updatePose()` 调用了通用 solver。
- Rust 的启动、内存和尾部延迟收益需要测量，不能仅由语言切换承诺速度提升。
- 一次 SELFTEST PASS、4.370 V 读数和无 HMD 时的预览现象提供测试线索，分别不等于长期精度达标、LiHV 电池确认或骨架故障定论。
