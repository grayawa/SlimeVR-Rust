# 设备资料基线与证据范围

资料来源为用户提供的 `SlimeVR_rewrite_bundle_2026-09-30.zip`，包含讨论、设备配置、协议、esptool 记录与上游引用。2026-10-03 核对的 19 个文件均与包内 SHA-256 清单匹配；该校验覆盖资料完整性，设备运行事实采用资料中的测试条件。

## 设备与协议

资料首套样本为 ESP8285、LSM6DSV、协议 22 和固件字符串 `good`。`BOARD=9` 与 `IMU=13` 对应 Server 枚举，MCU、晶振、Flash 等信息来自包内记录。厂商 fork 的实际行为以其源码和设备采集为准；`81c57e2` 的上游来源仍待确认。

固件字符串按握手原值保留。方向在线路中为 `xyzw`，核心字段为 `wxyz`；包 23 使用 Q15 四元数和 Q7 加速度。设备融合、UDP 轴变换与身体安装校准各自应用一次，接收契约见 [后端指南](rust-backend-rewrite-plan.zh-CN.md#接收契约)。

## 校准与时间

设备 runtime gyro-bias、TCAL 温度曲线、temperature-gradient 辅助、服务端复位与 StayAligned 各有独立输入和作用。资料中的 240 / 120 / 60Hz、温度校准点与约 5°C 间隔属于指定上游路径，厂商设备的实际时序需要采集。

主机的 socket 接收时刻、处理时刻和设备采样时刻分开记录。缺失遥测与采样时刻标记为未知。SELFTEST、电压和预览结果按各自测试条件解读，长期精度、电池体系与世界锚点另行验证。

## 六点实机样本

首套验收布局为胸、髋、双大腿、双小腿，手部使用 VR 控制器。采集内容包括设备身份 / sensor / 身体部位映射、协议 22 原始包、每 sensor 更新间隔、实际遥测、HMD / 控制器锚点、动作、重置和配置。

动作覆盖静止、转身、行走、蹲坐、热机、停更与恢复。脚方向回退、控制器输入和左右佩戴按此布局验收；上臂、脚部独立 sensor 和手指 IMU 使用各自样本。网络检查包括 2.4GHz、UDP 可达性、AP isolation 和防火墙，路由拓扑按实际环境记录。

## 研究数据与操作

公开 fixtures 使用匿名身份与脱敏的协议 / 动作记录，原始 Flash、配置和网络凭据保存在私有材料中。串口查询、诊断、保存、删除校准、恢复出厂和刷写分别记录执行条件及影响。采集首套回归时沿用设备现有固件与校准状态。

当前服务处理既有融合四元数。raw / DUAL 协议、Server-side VQF、时钟同步、长期温漂学习、Deep Static、ML 与常驻生命周期属于独立设计项目。当前结构见 [后端指南](rust-backend-rewrite-plan.zh-CN.md)，实机步骤见 [统一清单](rust-unified-hardware-test.zh-CN.md)。
