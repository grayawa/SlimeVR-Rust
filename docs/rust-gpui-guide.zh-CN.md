# GPUI 架构、页面与交互

原生桌面界面位于 `gui-gpui/`，采用 [GPUI Kit](https://gpui-kit.com/) 0.7.1 和匹配的 GPUI 依赖，应用与组件由 `gui-gpui/Cargo.lock` 共同锁定。GPUI 与 React / Tauri 共用 Rust 后端和 SolarXR 协议。构建及功能入口见 [README](../gui-gpui/README.zh-CN.md)。

## 分层

| 层         | 主要文件                                               | 职责                                                   |
| ---------- | ------------------------------------------------------ | ------------------------------------------------------ |
| 应用与页面 | `src/view.rs`、`src/view/`                             | 导航、引导、表单、设备操作、预览和页面状态             |
| 设置状态   | `src/settings.rs`、设置目录与布局数据                  | 草稿、字段映射、范围校验、保存确认和返回恢复           |
| 通信       | `src/client.rs`、`protocol.rs`、`rpc_generated.rs`     | WebSocket、FlatBuffers、事务号、订阅、最新帧与操作事件 |
| 桌面宿主   | `src/desktop.rs`、`tray.rs`、`logging.rs`、`sounds.rs` | 后端生命周期、单实例、托盘、日志和音频工作线程         |
| 组件库     | `ui/`（`slimevr-ui` crate）                            | 受控组件、当前主题颜色、尺寸和交互组合                 |
| 应用主题   | `src/theme.rs`                                         | SlimeVR 主题预设                                       |
| 翻译与资源 | `src/i18n.rs`、`locales.rs`、`assets/`                 | Fluent、回退、字体、图片、模型和声音                   |

网络和阻塞操作在后台执行，UI 线程应用状态并绘制。通信、UI、后端解算和输出分别控制频率。详细后端边界见 [API 架构](rust-backend-api-architecture.zh-CN.md)。

## 交互契约

主侧栏保留主界面、追踪器分配、佩戴校准、身体比例、连接追踪器及底部设置。主页提供重置、设备分组、检查清单、骨架预览和录制 / 暂停 / VR 控制。

设备卡片和表格按 GUI 偏好分组、排序并显示开发信息。Wi-Fi 图标与延迟使用实际遥测，悬停显示 dBm；缺失数值为未知，断联为灰色。电池使用原版形状与填充、低电量颜色、充电闪电、满电勾号和断联灰色，悬停提供实际电量、电压与续航。

旋转与线性加速度变化触发主页、选择菜单、引导连接列表和人物部位的高亮，停止晃动后光晕消退。该反馈只更新显示状态，分配由选中或敲击操作完成。

设置使用原分组、标题、说明、控件顺序与字段映射。侧栏和设置卡片之间、独立卡片之间均为 8px 间距，圆角由独立卡片绘制。SteamVR 页显示驱动状态与自动分配控件，检查清单按原状态规则排序、阻塞与显示。

### 分配与校准

分配页面复用人物与身体部位布局。点击部位打开分组设备卡片弹窗，支持两次敲击选择、“不分配”和颈部说明。窄窗口使用追踪点下拉选项，引导共用同一分配界面。

佩戴页面提供位置选择、四步校准与手动方向轮盘。比例页面提供身高预览、分组长度 / 比例、导入导出、默认值与 AutoBone。覆盖手动比例前先确认。设备详情和串口控制台按当前连接显示操作状态。

### 引导与返回

首次启动根据已保存的完成状态进入引导。“引导”入口可以再次打开。流程包括欢迎、设备类型、Wi-Fi / 接收器、连接确认、分配、佩戴、身高、用途和动作捕捉偏好；各步骤共享正式页面的设备与表单逻辑。

VRChat 设置警告在设置区域显示，返回时恢复来源页、滚动和未保存草稿。跨页面设置草稿保留编辑，保存按受影响设置组提交并核对回包，失败或超时保留草稿。

### 连接、草稿与操作事件

姿态与遥测使用最新快照，RPC 结果、错误、敲击和重置进度使用操作事件。重连恢复读取与订阅，用户操作按当前连接会话确认。设置响应更新服务器状态，草稿保留用户编辑；保存只提交受影响的设置组，确认后结束等待。失败或超时保留草稿。

分配模式按页面和连接生命周期切换。音效按会话、事务、阶段和秒数去重；通信线程将重置进度直接送入音频线程，音频素材在线程启动时预解码。播放顺序遵循原版素材。

### 退出与反馈

在线且未超时的 IMU 追踪器触发居中退出提醒，使用原 Fluent 文案与上下排列的退出 / 等会按钮。Esc 和遮罩点击取消关闭，页面和草稿保持当前状态。确认退出停止配网并关闭自己启动的后端；外部服务由原启动方式管理。

重置按钮按请求状态禁用，显示服务端倒计时与完成。GPUI 通信线程将去重后的重置进度送入音频线程，播放与 UI 刷新分别推进。原生窗口状态、来源设备与 API 状态决定可用操作。

## 组件和生成数据

`slimevr-ui` 的 `ui/src/components/` 提供设置面板、单选卡片、数值加减条与开关行。组件负责布局和当前主题样式；页面负责翻译、状态、参数语义、校验和 RPC。应用、Overlay 与组件预览直接依赖该 crate。SlimeVR 主题预设由应用层提供。组件接口与独立预览见 [组件库](rust-gpui-components.zh-CN.md)。

Fluent 翻译、原素材、RPC 适配和设置字段布局通过仓库生成脚本整理。修改生成内容时先更新源数据或生成器，再生成目标文件。后端设置保存到 YAML，GUI 偏好沿用既有设置文件。

## 平台与分发

Windows 渲染器通过 `runtime-shaders` 嵌入 HLSL 和共享 include，在内存中编译优化 shader。`vr-dashboard` 为仪表盘程序提供 D3D11 共享纹理提交。渲染器补丁位于 `vendor/gpui-pre-windows/`。

**Build GPUI** 构建独立桌面测试包，**Build Overlay** 构建仪表盘附加包，**SlimeVR AIO Release** 构建发布合集。完整流程见 [构建与分发](rust-distribution.zh-CN.md)。Windows / Linux 完整桌面包附带后端、驱动、OpenVR helper、许可证和源码版本说明。Linux 的原生构建、Vulkan 依赖、StatusNotifier 托盘和 udev 权限规则见 [前端 README](../gui-gpui/README.zh-CN.md)。

## 性能与验收

使用 release 构建，并对齐后端、追踪器数量、订阅频率、预览状态、窗口大小和日志级别。前端按进程树记录私有内存、工作集、CPU 与 GPU 内存，后端单独记录；Tauri 的测量范围包含其 WebView2 子进程。

测试场景包括空闲、六设备主页、分配页切换、预览开关、最小化、断联恢复和连续运行。性能结论限定到等价场景和实际测量环境。

功能验收覆盖配置与草稿保存、VRChat 返回、单次重置与音效、已有驱动提示、BVH 收尾、日志轮转、中文输入、DPI、多屏和显卡。自动检查覆盖 RPC 编解码、导航、草稿、设备状态、检查清单、翻译、音效、订阅、偏好和真实后端回环。原生渲染与打包检查随平台构建执行，结果以对应 Actions 运行记录为准。实机步骤见 [统一清单](rust-unified-hardware-test.zh-CN.md)。

## 显示与集成范围

骨架和追踪器用 GPUI 原生绘图展示真实三维数据，材质及引导布局与网页不同。新增文案提供中文 / 英文，其余语言复用原翻译并回退英文；系统对话框取决于操作系统语言。固件构建需要已有固件服务，其地址可配置。Discord 需要本机客户端。

诊断使用本地日志。SteamVR 驱动、仪表盘与第三方资源由对应组件管理。设置控件按现有前端与后端共同实现的操作生成。
