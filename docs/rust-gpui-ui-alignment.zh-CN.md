## test11 退出时追踪器仍开机提醒

原版 `TrackersStillOnModal` 是覆盖整个窗口的居中弹窗；GPUI 此前把一行通用提醒追加在页面末尾，长页面可能滚动后才看见。现在恢复居中遮罩、标题与说明、上下排列的“退出 SlimeVR” / “等会…”按钮，直接使用原 `trackers_still_on-modal-*` Fluent 文案。中文布局与实际渲染的原 React 窗口对照，370px 弹窗、24px 内边距、12px 间隔、40px 按钮，窄窗口仍居中。

取消按钮、Esc 与点击遮罩均返回原页面，保留未保存的设置；点击说明不会取消，遮罩点击不穿透到侧栏。退出提醒位于其他页面弹窗之上，Esc 优先关闭退出提醒。关闭回调已借用窗口，因此焦点恢复改在回调结束后执行，确保键盘取消可用。

提醒条件遵循原版：当前连接会话中有 `is_imu` 且既非 DISCONNECTED、也非 TIMED_OUT 的追踪器；包括 BUSY / ERROR 状态。头显、手柄和计算节点不触发，提醒关闭或数据会话断开时直接退出。启用托盘时，标题栏关闭与系统关闭统一隐藏窗口；托盘退出仍执行真正退出提醒。确认后走同一退出流程，停止配网，自启动后端通过 stdin EOF 正常结束；连接现有服务时保留它。这是退出提醒，没有增加远程关闭设备电源的命令。

验证：57 项自动测试通过，1 项外部测试未启用；Linux / Windows GNU Clippy（`-D warnings`）、格式检查和 Windows release 构建通过。原版 React 窗口及 GPUI 原生 Linux 窗口均连接真实 Rust 后端和六台模拟 UDP 设备；验证主页 / 设置、取消按钮、Esc、遮罩、重复关闭、未保存设置保留、800 × 560 布局，以及连接外部后端时退出保留服务、自启动后端确认退出后子进程结束。全部使用临时配置；Windows 系统关闭、托盘及真实设备仍待实机测试。

## test10 电量显示

此前电量百分比已接入，但主页及详情的电池图标只是 `▰` 占位字符，未还原填充、低电量颜色和充电状态。现在使用原 `BatteryIcon` 的形状和 19 × 11 尺寸绘制原生图标，主页卡片、表格、分配弹窗和详情共用显示。

与原版相同：电量高于 40% 为绿色，高于 20% 为黄色，1–20% 为红色；0% 为空，断联变灰。电压高于 4.3 V 时显示充电闪电，原协议 101–200 的满电标记显示勾号；201–255 按 0% 显示。未上报电量时隐藏组件，不虚构读数。充电时普通百分比位置显示短灰条，沿用原版行为。

补齐 SolarXR 的续航估算解码，单位保留为微秒：普通模式显示 `xh ymin`，debug / moreInfo 同时显示百分比；表格和详情的 moreInfo 在调试模式下附加电压。悬停显示电量、电压、已上报的续航及充电状态，新增文案接入 Fluent 中文 / 英文与其他语言的回退。现有 Rust 后端尚未生成设备续航估算，因此续航仅在所连接后端上报此字段时出现。

验证：54 项自动测试通过，1 项外部测试未启用；Linux 与 Windows GNU Clippy（`-D warnings`）、格式检查和 Windows release 构建通过。原生 Linux 窗口连接真实 Rust 后端和六台模拟 UDP 设备，检查 0 / 20 / 40 / 82 / 100%、缺失电量、充电、断联、主页卡片 / 表格、分配弹窗及 800 × 560 布局。另用本机 SolarXR 测试代理注入续航、满电标记和 255，检查普通 / 调试模式及详情的电压和多行布局；代理仅用于验证，没有加入产品。Windows 实机与真实硬件读数仍待测试。

## test9 晃动追踪器高亮

原版 `useTracker().useVelocity()` 根据原始旋转和线性加速度的变化，累计约半秒的运动量，给主页卡片、表格、连接列表和设备选择卡片绘制紫色光晕。此前 GPUI 只把运动量接到人物部位，设备卡片和表格仍只响应敲击通知。

现在上述卡片和表格共用运动检测与光晕：强度沿用原版旋转差 `sin²(角差 / 2) × 50` 和线性加速度差平方和 `/ 1000`，累计值限制到 0–1，卡片光晕的模糊与扩散半径为 `floor(强度 × 8)`。人物标签也随运动量显示光晕，节点边缘随强度变化；分配、手动佩戴及引导共用此显示。设备选择的当前部位边框、警告和已有敲击逻辑保留。

补齐数据流中的线性加速度，保留原始加速度供现有遥测使用；computed 卡片也可响应其旋转。首个样本只建立基准，停止后半秒窗口清空，断开或切换后端会话清除旧状态，四元数正负等价和无效数据不产生误高亮。晃动不修改分配、不发送设置、不触发音效，也没有提高现有数据流频率。

本包保留 test8 引导、test7 Wi-Fi 显示及手部切换修复。设备详情页主卡沿用原版 `shakeHighlight={false}` 的行为。

验证：48 项自动测试通过，1 项外部测试未启用；Linux 与 Windows GNU Clippy（`-D warnings`）和 Windows release 构建通过。原生 Linux 窗口连接真实 Rust 后端和六台模拟 UDP 设备，检查了单台旋转时主页卡片 / 表格、人物部位、设备选择弹窗、引导连接列表的光晕，停止、断开与重新连接后的清除，以及 800 × 560 布局。另保持旋转固定，仅改变 UDP 加速度数据，确认线性加速度能点亮对应卡片；晃动和关闭选择弹窗前后，分配 YAML 不变。测试配置与日志均位于临时目录；随包后端与 test8 完全相同，Windows 11 实机仍待测试。

## test4 卡片间距修正

原版 `SettingsPageLayout.tsx` 只有各卡片自身带背景与圆角；设置表单使用 `gap-2`（8px），`SettingsLayout.tsx` 在设置侧栏与内容间使用 `pl-2`（8px）。此前 GPUI 缺少这条横向间距、卡片间距为 16px，外层滚动容器也带圆角，导致同色区域在左边缘相接并形成凹槽。
