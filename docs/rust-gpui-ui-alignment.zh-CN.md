# GPUI 页面布局与交互契约

GPUI 以仓库 `gui/src` 的 React / Tauri 界面为布局参照，共用后端、SolarXR、原版 Fluent 与素材。对照窗口采用中文、Slime 主题、1280 × 800 与六台模拟设备；窄窗口和主题切换另行检查。

## 主页、侧栏与设置

主侧栏保留主界面、追踪器分配、佩戴校准、身体比例、连接追踪器及底部设置。主页提供重置、设备分组、检查清单、骨架预览和录制 / 暂停 / VR 控制。

设备卡片和表格按 GUI 偏好分组、排序并显示开发信息。Wi-Fi 图标与延迟使用实际遥测，悬停显示 dBm；缺失数值为未知，断联为灰色。电池使用原版形状与填充、低电量颜色、充电闪电、满电勾号和断联灰色，悬停提供实际电量、电压与续航。

旋转与线性加速度变化触发主页、选择菜单、引导连接列表和人物部位的高亮，停止晃动后光晕消退。该反馈只更新显示状态，分配由选中或敲击操作完成。

设置使用原分组、标题、说明、控件顺序与字段映射。侧栏和设置卡片之间、独立卡片之间均为 8px 间距，圆角由独立卡片绘制。SteamVR 页显示驱动状态与自动分配控件，检查清单按原状态规则排序、阻塞与显示。

## 分配与校准

分配页面复用人物与身体部位布局。点击部位打开分组设备卡片弹窗，支持两次敲击选择、“不分配”和颈部说明。窄窗口使用追踪点下拉选项，引导共用同一分配界面。

佩戴页面提供位置选择、四步校准与手动方向轮盘。比例页面提供身高预览、分组长度 / 比例、导入导出、默认值与 AutoBone。覆盖手动比例前先确认。设备详情和串口控制台按当前连接显示操作状态。

## 引导与返回

首次启动根据已保存的完成状态进入引导。“引导”入口可以再次打开。流程包括欢迎、设备类型、Wi-Fi / 接收器、连接确认、分配、佩戴、身高、用途和动作捕捉偏好；各步骤共享正式页面的设备与表单逻辑。

VRChat 设置警告在设置区域显示，返回时恢复来源页、滚动和未保存草稿。跨页面设置草稿保留编辑，保存按受影响设置组提交并核对回包，失败或超时保留草稿。

## 主题与组件

`ui/components/` 提供设置面板、单选卡、数值加减条和开关行，`ui/theme.rs` 提供实时颜色与统一尺寸。页面负责业务状态、参数范围、校验和 RPC。

单选卡采用主题卡片背景和选中边框，说明按实际宽度换行并跟随设置字号。数值条以同一浅背景组织减号、数值和加号。组件在构建时读取当前主题，Slime、Light、Green 与高对比度使用对应颜色。

独立组件预览使用内存示例值，展示长中英文、12 / 16 / 20px、窄窗口、禁用状态和主题切换。接口与预览运行方式见 [组件库](rust-gpui-components.zh-CN.md)。

## 退出与反馈

在线且未超时的 IMU 追踪器触发居中退出提醒，使用原 Fluent 文案与上下排列的退出 / 等会按钮。Esc 和遮罩点击取消关闭，页面和草稿保持当前状态。确认退出停止配网并关闭自己启动的后端；外部服务由原启动方式管理。

重置按钮按请求状态禁用，显示服务端倒计时与完成。GPUI 通信线程将去重后的重置进度送入音频线程，播放与 UI 刷新分别推进。原生窗口状态、来源设备与 API 状态决定可用操作。

## 检查方式

自动检查覆盖导航、草稿、设备状态、检查清单、翻译、设置布局、声音、订阅和偏好。原生窗口对照检查分配弹窗、引导、校准、比例、设备详情、串口、主题和窄窗口；保存后核对 YAML，预览与草稿按各自提交规则检查。

Windows 实机检查中文输入、DPI、多屏、显卡、声音、退出提醒、SteamVR 与真实设备，按 [功能验收](rust-gpui-functional-parity.zh-CN.md) 和 [统一清单](rust-unified-hardware-test.zh-CN.md) 执行。自动状态检查、截图和受控输入分别提供其覆盖范围内的证据。
