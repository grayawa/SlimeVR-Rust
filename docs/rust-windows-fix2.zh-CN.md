# 重置倒计时音效与左右佩戴检查

## 重置通知与声音

服务端沿用 `ResetTimer.kt` 的整秒通知规则，每个整秒发送一次进度，完成进度等于设定的倒计时时长。前端按操作、阶段与秒数处理通知并去重。

GPUI 的通信线程将 ResetResponse 直接送入音频队列，音频线程在启动时预解码素材并按原版顺序播放。Tauri / React 使用现有声音素材和进度处理。实机分别检查完整重置与安装方向重置的完整倒计时序列。

自动回归通过实际 SolarXR 请求触发倒计时，以 4ms 间隔推进时钟，覆盖 3 秒、2.5 秒及 0.5 秒的通知和单次执行。GPUI 测试同时覆盖 UI 暂停刷新期间的声音序列与重复回包。

## 左右佩戴与脚部验证

左右腿设备的身体分配和实际佩戴位置需要一致。调整佩戴后重新执行完整重置与安装方向重置，再检查抬单腿、支撑脚、转身和蹲坐。

四组 Kotlin 原算法参考覆盖左右腿单独抬起以及骨骼约束开关。受控用例中的脚锁定状态逐帧一致，最大位置差小于 0.001mm；接触评分使用独立浮点容差。实机动作按 [统一测试清单](rust-unified-hardware-test.zh-CN.md) 验收。

启动和日志见 [便携包说明](rust-windows-portable.zh-CN.md) 与 [日志收集](rust-logging.zh-CN.md)。
