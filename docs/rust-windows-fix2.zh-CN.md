# Windows 修复包 fix2

适用于 Windows 11 x64，包含 fix1 的连接、设备发现与日志修复。继续使用系统 WebView2 和原版 `vrconfig.yml` / `vrconfig.yaml`。

## 重置倒计时音效

原版前端收到重置进度通知时会播放对应的倒计时音效。Rust 后端此前每 100 毫秒通知一次，造成进入下一秒后同一段音效反复从头播放。

后端现按原版 Java `ResetTimer.kt` 的行为，每个整秒只通知一次。重置完成通知的进度等于实际设定的倒计时时长。

回归测试通过实际 SolarXR 重置请求触发倒计时，以 4 毫秒间隔推进服务时钟，检查 3 秒、2.5 秒及 0.5 秒倒计时的完整通知序列，确认没有重复通知且只执行一次重置。

## 支撑脚漂移排查

本次实机排查中，左右腿追踪器戴反。换回正确位置并重新进行完整重置及安装方向重置后，用户确认支撑脚恢复正常，因此本包不改动腿部算法。

新增四组 Kotlin 原算法对照用例，覆盖左右腿单独抬起及骨骼约束开启/关闭。脚部锁定状态逐帧一致，最大位置差小于 0.001 毫米。接触评分因约束计算后的浮点误差使用单独容差，位置与锁定状态仍保持原有检查精度。这些用例不代表所有实机动作都已验证。

## 验证与使用

114 个 Rust 测试与 22 个 GUI / 桌面 / 后端协议测试通过，Clippy 无警告。Windows 后端使用 release 交叉编译，打包检查 PE 架构、DLL 依赖、文件校验值及 ZIP 完整性。本环境未执行 Windows 原生运行，音效播放仍需在实机确认。

退出旧版后使用新包启动，保持左右腿的设备分配与佩戴位置一致。沿用现有配置，无需清空配置或重新安装 WebView2。

日志位置：`%APPDATA%\dev.slimevr.SlimeVR\logs\gui-tauri.log`。
