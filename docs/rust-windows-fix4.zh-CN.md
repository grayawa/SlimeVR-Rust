# 追踪器分配页面的生命周期

分配页面按挂载、卸载和连接恢复切换敲击分配模式。写入请求只包含 `setupMode`，其他敲击参数按后端当前值保存。SettingsResponse 更新界面读取状态，分配模式的切换由页面和连接生命周期触发。

连接断开时，卸载清理跳过发送；恢复连接后按当前页面重建分配模式。导航布局引起的重新挂载可以产生对应的模式开关，页面稳定后保持当前模式。

自动浏览器检查使用生产网页和真实 Rust 后端，覆盖停留期间的连接与数据流、其他设置更新、离页关闭、再次进入、主动断线恢复以及原有敲击参数保留。

实机检查：进入“追踪器分配”停留一分钟，再来回切换页面，确认设备更新、敲击选择和连接状态。遇到异常时记下发生时间并收集 [日志](rust-logging.zh-CN.md)。
