# Windows 更新包 fix5：日志分级

包含 fix1–fix4 的修复；fix4 的分配页连接稳定性已获用户实机反馈确认。

本版统一前端、桌面进程和它启动的 Rust 后端日志级别，默认 `info`。完整姿态与设备快照降到 `debug`，逐样本和遥测降到 `trace`；连接异常保留关闭码、原因和后端诊断。新增毫秒时间和来源字段，避免原生进程状态被前端重复写入。常规级别保留设备连接、SteamVR 状态变化、重置完成和 BVH 导出结果。

日志按约 10 MiB 轮转，保留当前文件和四份历史文件；旧超大日志首次写入时移入历史文件，保留原有内容。调试入口为 `Start-SlimeVR-Debug.cmd`，必须先完全退出已有实例；再次正常启动即恢复默认级别。提交日志时请压缩整个 `logs` 文件夹。使用步骤与开发参数见随包 `日志说明.md`。

配置继续使用 `vrconfig.yml` / `.yaml`，没有新增 JSON 配置文件。本次只调整日志和诊断输出，算法、设备收包、SteamVR 姿态发送及录制流程保持现有行为。

验证包括 117 项 Rust 测试、9 项原生宿主测试、27 项前端与协议测试，以及生产网页和真实后端的分配页浏览器回归。另通过 TypeScript、改动文件 ESLint / Prettier、Rust Clippy、生产网页构建及 Windows release 交叉编译。日志测试覆盖默认级别过滤、debug / trace 恢复详细输出、命令行与环境变量优先级、警告与错误保留、并发写入、轮转和录制回放兼容。依赖完整快照的旧协议测试现在显式指定 `debug`，避免在默认无快照模式下形成空断言。

ZIP 完整性、PE / DLL 依赖和内嵌生产网页资源另行校验。本环境没有执行 Windows 原生运行；本次日志收集入口和 Windows 文件轮转仍待实机验证。
