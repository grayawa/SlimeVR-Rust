# Windows 日志使用说明

前端、桌面进程和桌面启动的后端使用统一日志级别，默认 `info`。常规日志保留设备连接、SteamVR 状态、重置完成、BVH 导出、警告和错误。`debug` 提供完整姿态与设备快照，`trace` 提供逐样本和遥测记录。

日志包含毫秒时间、来源和实际级别。文件按约 10MiB 轮转，保留当前文件与四份历史文件；每条记录刷新到持久句柄。后端诊断的管道写入由专用线程执行。具体时序指标、队列策略和路径见 [完整日志说明](rust-logging.zh-CN.md)。

排查时完全退出已有实例，使用 `Start-SlimeVR-Debug.cmd` 启动，复现后压缩整个 `logs` 文件夹并附上时间与操作。正常方式重新启动后使用默认级别。

自动检查覆盖级别过滤、参数优先级、错误保留、并发写入、轮转与录制回放；依赖快照的通信测试使用显式 `debug`。实机检查关注调试启动、异常退出和 Windows 文件轮转。
