# Embedded fonts

Poppins-Regular.ttf is from google/fonts ofl/poppins. Poppins-OFL.txt is its license.
Noto Sans, Lexend, Ubuntu and OpenDyslexic were converted from the original gui/public/fonts WOFF / WOFF2 assets to TTF using fontTools. The Lexend variable font was instantiated at its default axes. Font names are preserved.
NotoSans-OFL.txt and Lexend-OFL.txt are from google/fonts; Ubuntu-UFL.txt is the Ubuntu Font Licence. OpenDyslexic is by Abbie Gonzalez and uses the SIL Open Font License 1.1, recorded in OpenDyslexic-OFL.txt.

Sources:

- https://github.com/google/fonts/tree/main/ofl/poppins
- https://github.com/google/fonts/tree/main/ofl/notosans
- https://github.com/google/fonts/tree/main/ofl/lexend
- https://github.com/google/fonts/tree/main/ufl/ubuntu
- https://forge.hackers.town/antijingoist/open-dyslexic

Portable packages include these font sources, conversion notes and license files.

Poppins-Bold.ttf and Ubuntu-B.ttf use the same upstream sources and licenses listed above. OpenDyslexic-Bold.ttf is converted from the original OpenDyslexic-Bold.woff. Both regular and bold weights are embedded so native section titles use the requested weight.
